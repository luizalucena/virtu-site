🕐 Expiração Automática (pg_cron)

A função fn_expirar_premios() é agendada automaticamente para rodar diariamente às 03h00 (Recife) via pg_cron.

O que ela faz: expira cupons vencidos → desativa o cupom no sistema → reseta o contador da cliente para 0.

Para ativar, habilite a extensão pg_cron em Supabase → Database → Extensions. A migration já agendou a rotina automaticamente se a extensão estiver ativa.
